# 🗺️ Map Visualizer – State & District Population Dashboard

## 📖 Project Description
Map Visualizer is an interactive Streamlit dashboard that visualizes population data across Indian states and districts using choropleth maps.

The application allows users to explore state and district population details and compare demographic statistics using interactive geographic visualizations.

---

## 🎯 Features
- Interactive state-wise population visualization
- District-level population mapping
- Multi-district selection and comparison
- Optional district border highlighting
- Customizable border colors
- Interactive hover information
- Side-by-side state and district maps

---

## 🛠 Technologies Used
- Python
- Streamlit
- Pandas
- Plotly Express (Choropleth Maps)
- GeoJSON for geographic visualization

---

## 📊 Dataset Information
The dashboard uses population data containing:
- State name
- District name
- Total population
- Male population
- Female population

Required files:
- `State_district_combined.csv`
- `india_states.geojson`
- `dist.geojson`
